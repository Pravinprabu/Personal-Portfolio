IEEE Conference · Published 🏆 First Prize

IRRIS — Iterative Run Reversal & Integration Sort A formal specification, complexity analysis and empirical evaluation

M. Kanniga Parameshwari, Krish Mehta, Yukesh J, Pravin P, Krishanth G, Sudhir R

Real data is rarely random: it's full of stretches that are already ascending or descending. IRRIS is an adaptive, stable sort that detects both kinds of run in a single pass, reverses the descending ones, and merges the runs pairwise in balanced rounds. A hybrid_merge() step checks run boundaries in O(1) and simply concatenates runs that don't overlap, skipping merge work entirely.

The paper proves correctness, termination and stability, and benchmarks IRRIS against CPython's Timsort. IRRIS is up to 11× faster on sorted, reverse-sorted and partially reversed input, while Timsort stays stronger on random data.
